## 1. 平台概述

本平台是集团财务数据标准化处理与可视化系统，基于 **Vizro + Shiny 双引擎架构**：

| 引擎 | 定位 | 端口 | 启动方式 |
|------|------|------|---------|
| **Vizro** | 领导汇报大屏 — 穿透监控、地理分布、日报邮件 | 5001 | Flask 服务 |
| **Shiny** | 个人电脑办公大屏 — 14 页交互分析、AI 智能查询 | 8000 | `shiny run` |

两者共享同一个 DuckDB 数据仓库 (`data/warehouse/finance_warehouse.duckdb`)，底层数据通过 ETL 管道统一处理。

### 架构示意

```
Excel 原始文件 → Kedro ETL 管道 → DuckDB 数据仓库
                                      ├── Vizro (Flask, :5001)
                                      ├── Shiny (Shiny for Python, :8000)
                                      └── 共享模块 (my_finance_shared)
```

## 2. 环境准备

### 2.1 系统要求

- Linux (推荐) / macOS
- Python ≥ 3.13
- micromamba (推荐) 或 conda
- whiptail (图形启动器依赖，`sudo apt install whiptail`)

### 2.2 创建环境

```bash
# 使用预配置环境（推荐）
micromamba create -n shiny_vizro python=3.13 -y
micromamba activate shiny_vizro

# 安装全部依赖
pip install shiny shinywidgets shinychat plotly pandas polars duckdb \
    flask pyyaml python-dotenv numpy openpyxl vizro dash kedro \
    great-tables querychat anthropic fastexcel pyarrow
```

### 2.3 配置文件

| 文件 | 用途 |
|------|------|
| `conf/base/parameters.yml` | 数据库路径、邮件配置、文件缓存开关 |
| `conf/base/catalog.yml` | Kedro 数据目录定义 |
| `conf/base/finance_loader.yml` | Excel 解析规则 |
| `conf/base/treasury_loader.yml` | 资金账户解析规则 |
| `.env` | **环境变量** — 必须包含 `ANTHROPIC_API_KEY`（AI 智能查询需要） |

**.env 示例**：

```ini
ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxx
```

## 3. 数据准备与 ETL

### 3.1 原始数据目录结构

```
data/01_raw/
├── 2026年02月财务快报数据/
│   ├── 单位A-202602-财务.xlsx
│   └── ...
├── 2026年03月财务快报数据/
└── 2026年4月司库账户数据/
    ├── treasury_account_*.xlsx
    └── ...
```

### 3.2 运行 ETL 管道

```bash
# 完整管道 (财务 + 资金 + 地理编码)
python -m src.my_finance_etl

# 仅财务快报
kedro run --pipeline finance_report

# 仅资金账户
kedro run --pipeline treasury_data

# Polars 加速模式
kedro run --pipeline ingest_polars

# 查看所有管道
kedro registry list
```

### 3.3 管道说明

| 管道名 | 功能 | 说明 |
|--------|------|------|
| `__default__` | 完整管道 | 财务 + 资金 + 数仓 + 地理编码 |
| `ingest` | 财务摄入 (Pandas) | 兼容模式 |
| `ingest_polars` | 财务摄入 (Polars) | 高性能模式 |
| `process` | 指标标准化 | 科目匹配 + 标准化 |
| `warehouse` | 数仓构建 | DuckDB 星型模型 |
| `finance_report` | 财务快报链路 | 摄入→处理→入库 |
| `treasury_data` | 资金数据链路 | 摄入→处理→银行网点→地理编码→入库 |
| `dim_bank_branch` | 银行网点维度 | CNAPS XML 丰富 |
| `enrich_geo_coordinates` | 地理编码 | 高德 API 坐标获取 |

## 4. 启动与停止服务

### 4.1 图形启动器（推荐）

```bash
bash start.sh
```

弹出 whiptail 菜单：

```
┌────────────────────────────────────────────┐
│        财务数据分析平台 v1.6.0               │
│                                            │
│  两个服务将同时启动。请选择打开的页面:          │
│                                            │
│    ○ 领导汇报大屏 (Vizro)    port 5001      │
│    ○ 个人电脑办公大屏 (Shiny)  port 8000     │
│                                            │
└────────────────────────────────────────────┘
```

选择后两个服务**同时启动**，浏览器自动打开选中页面。日志写入 `logs/` 目录。

### 4.2 手动启动

```bash
# 启动 Vizro（领导汇报大屏）
micromamba run -n shiny_vizro python -c "
from src.my_finance_web import create_app
create_app().run(debug=False, host='0.0.0.0', port=5001)
" > logs/vizro.log 2>&1 &

# 启动 Shiny（个人电脑办公大屏）
micromamba run -n shiny_vizro shiny run \
    --host 0.0.0.0 --port 8000 \
    src.my_finance_shiny.app \
    > logs/shiny.log 2>&1 &
```

### 4.3 停止服务

```bash
bash stop.sh
```

该脚本会同时停止 5001 和 8000 端口的进程。

### 4.4 服务地址

| 服务 | 地址 |
|------|------|
| Vizro 领导汇报大屏 | http://localhost:5001 |
| Shiny 个人电脑办公大屏 | http://localhost:8000 |

## 5. Vizro 领导汇报大屏

Vizro 是面向**领导汇报场景**的仪表板，运行在 **port 5001**。

### 5.1 页面导航

```
🏠 首页
├── 📊 穿透监控大屏          — 资产负债气泡散点 + 杠杆率分析
├── 🗺️ 账户地图              — 全国账户地理分布（四维筛选）
├── 📋 账户明细表            — AgGrid 交互式表格（筛选+导出）
├── 🔍 穿透监管              — 逃逸账户 + 账户数量异常检测报告
├── 📊 余额统计分析
│   ├── 整体情况             — KPI 卡片 + 直方图 + 饼图
│   ├── 子集团维度           — 水平柱状图 + Treemap
│   ├── 所属银行维度         — 柱状图 + 饼图 + 堆叠柱状图
│   ├── 地理维度             — Top 20 城市余额排名
│   └── 交叉维度             — 散点图 + 箱线图
└── 🌏 地理分布              — 单位地理坐标中国地图
```

### 5.2 关键交互

- **账户地图**：支持子集团/所属银行/省份/城市四维筛选，省份→城市级联
- **AgGrid 明细表**：支持排序、筛选、分页
- **穿透监管报告**：直接返回 HTML 报告文件

## 7. AI 智能查询

智能查询是 Shiny 仪表板的核心页面，基于 **QueryChat + Anthropic Claude** 实现自然语言数据探索。

### 7.1 使用方式

1. 切换到「智能查询」页面
2. 在左侧聊天框输入自然语言问题
3. LLM 自动将问题转换为 SQL 过滤条件
4. 页面所有组件**联动更新**：KPI 卡片、地图、表格

### 7.2 查询示例

| 问题类型 | 示例 |
|---------|------|
| 按子集团筛选 | "显示北方公司的所有账户" |
| 按金额筛选 | "余额大于1000万的账户有哪些" |
| 按地区筛选 | "香港地区有哪些美元账户" |
| 按银行筛选 | "合作银行的账户，按余额从高到低" |
| 组合条件 | "凌云集团在中国工商银行的账户" |
| 统计分析 | "各子集团的账户数量和余额总和" |

### 7.3 页面组件说明

| 区域 | 组件 | 说明 |
|------|------|------|
| 顶部 | KPI 卡片 ×3 | 账户总数、余额合计、银行类型分布（三列彩色） |
| 中部 | 地理分布图 | 国内城市 + 海外国家散点地图 |
| 下部 | 子集团细分维度表 | great_tables 格式化表格，含财务快报数据 |
| 底部 | 账户明细表 | 交互式 DataTable，支持导出 CSV |

### 7.4 导出功能

每个表格右上角有「导出 CSV」按钮，文件名格式：
```
智能查询_子集团细分维度_20260525_143021.csv
智能查询_账户明细_20260525_143021.csv
```

### 7.5 财务快报数据集成

子集团维度表中的 **财务公司存款(快报)** 和 **商业银行存款(快报)** 两列数据来源于资产负债表 **货币资金** 科目，单位已转换为**亿元**。表格标题显示双日期：

```
司库数据截至 2026-04-30　　财务快报数据截至 2026-03-31
```

## 8. 报告生成与邮件发送

### 8.1 日报生成

在 Vizro 页面点击「生成日报」按钮，系统调用 Quarto 渲染 PDF 报告。

```bash
# 手动生成
cd /path/to/PrettyDoc
quarto render daily_report_account.qmd \
    -P year=2026 -P month=5 -P day=25
```

### 8.2 邮件发送

在 Vizro 页面点击「发送日报」按钮，系统自动：
1. 检查 PDF 是否存在（不存在则生成）
2. 调用 SMTP 脚本发送邮件

配置在 `conf/base/parameters.yml` 的 `email` 节：

```yaml
email:
  from: "sender@example.com"
  to: "receiver@example.com"
  subject_prefix: "[财务日报]"
```

## 10. 故障排除

### 服务无法启动

| 症状 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: No module named 'xxx'` | 缺少依赖 | `micromamba activate shiny_vizro && pip install xxx` |
| `Port already in use` | 端口被占用 | `bash stop.sh` 后重新启动 |
| `ImportError: attempted relative import` | 未以模块方式运行 | 确保在项目根目录，使用 `src.my_finance_shiny.app` 而非文件路径 |
| `ANTHROPIC_API_KEY not found` | 缺少 API 密钥 | 检查 `.env` 文件，确保包含 `ANTHROPIC_API_KEY` |

### DuckDB 锁定

```
IO Error: Could not set lock on file ... duckdb
```

多个进程同时写 DuckDB 时会冲突。解决：

```bash
# 1. 停止所有服务
bash stop.sh

# 2. 检查是否还有进程占用
lsof data/warehouse/finance_warehouse.duckdb

# 3. 杀掉残留进程后重启
bash start.sh
```

### AI 查询无响应

1. 检查 `.env` 文件中的 `ANTHROPIC_API_KEY` 是否有效
2. 检查网络是否能访问 Anthropic API
3. 查看 `logs/shiny.log` 中的错误信息

### 数据不更新

运行 ETL 管道后数据才会刷新：

```bash
micromamba activate shiny_vizro
python -m src.my_finance_etl
# 然后重启服务
bash stop.sh && bash start.sh
```

### 浏览器无法打开

`xdg-open` 在某些无桌面环境可能失败。手动在浏览器中输入对应地址即可：
- Vizro: http://localhost:5001
- Shiny: http://localhost:8000
