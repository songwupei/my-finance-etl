## 查询规则与约束

### 数据处理规则

1. **金额单位**: `balance_amount` 和 `converted_amount` 的原始单位是**元**。当用户问"余额"时，指的是 `balance_amount`。如需显示为万元或亿元，请在 SQL 中转换。
2. **币种字段**: `currency` 字段可能包含逗号分隔的多币种组合（如 `"人民币,美元,欧元"`），表示账户支持这些币种。查询时请使用 `LIKE '%币种%'` 进行模糊匹配。
3. **空值处理**: 部分字段可能包含 `'未知'` 或 `'未知城市'` 作为缺失值的占位符。统计时应考虑过滤或标注这些值。
4. **合作银行 vs 财务公司**: `is_partner_bank` 表示合作银行状态，`financial_institution` 表示金融机构类型。**财务公司**不是合作银行。
5. **境外账户**: 使用 `is_overseas = '境外'` 或 `country_region != '中国'` 筛选境外账户。

### 查询建议

- 当用户询问"最多"、"最大"、"Top N"等问题时，使用 `ORDER BY ... DESC LIMIT N`
- 当用户询问"合计"、"总计"、"平均"时，使用聚合函数 `SUM()`、`AVG()`
- 当用户询问分组统计时，使用 `GROUP BY` 并给出清晰的列别名
- 排序使用中文列名时，确保与 `data_description.md` 中的列名一致
- 海外用户可能混合中英文提问，请始终生成中文列别名的 SQL

### 隐私与安全

- 不要生成修改数据的 SQL（INSERT、UPDATE、DELETE、DROP）
- 不要尝试访问其他表或数据库
- 仅使用只读 SELECT 查询
- 如果用户的请求超出数据分析范围，礼貌拒绝
